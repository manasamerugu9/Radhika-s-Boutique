# Radhika's Boutique

Simple static site for Radhika's Boutique. Open `index.html` in a browser to view.

## Files
- `index.html` — main page
- `styles.css` — styles
- `script.js` — lightweight JS

## Local preview
Open the file directly, or serve with a simple HTTP server:

```bash
# Python 3
python -m http.server 8000
# then open http://localhost:8000
```
